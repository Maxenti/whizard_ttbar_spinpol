WHIZARD ttbar spin/polarization production package v1
=====================================================

Purpose
-------
Production-grade, HTCondor-sharded WHIZARD workflow for spin-correlated,
longitudinally polarized ttbar samples at sqrt(s) = 500 GeV, with ISR enabled.

Intended repository overlay
---------------------------
/afs/cern.ch/user/c/cglenn/FCCWork/whizard/whizard_ttbar_spinpol

Persistent campaign output root
-------------------------------
/eos/user/c/cglenn/FCCWork/whizard/whizard_ttbar_spinpol/production

Physics matrix
--------------
- Initial states: e- e+, mu- mu+
- Beam helicities: LR100, RL100
- Decay channels:
  * epmum: t -> b e+ nue; tbar -> bbar mu- numubar
  * mupem: t -> b mu+ numu; tbar -> bbar e- nuebar
- Spin treatment: exact correlated WHIZARD factorized decays
- ISR: enabled with recoil handler and explicit incoming-lepton mass
- Machine beam spectrum: disabled in v1
- Nominal production size: 10 shards x 10,000 events x 8 configurations
- Total nominal events: 800,000

Output policy
-------------
All persistent generated products are written below EOS. WHIZARD/O'Mega
compilation and event generation occur in local/Condor scratch. Raw WHIZARD
LHE files are retained unchanged; forced-decay-normalized LHE files are written
as separate products with JSON sidecars.
