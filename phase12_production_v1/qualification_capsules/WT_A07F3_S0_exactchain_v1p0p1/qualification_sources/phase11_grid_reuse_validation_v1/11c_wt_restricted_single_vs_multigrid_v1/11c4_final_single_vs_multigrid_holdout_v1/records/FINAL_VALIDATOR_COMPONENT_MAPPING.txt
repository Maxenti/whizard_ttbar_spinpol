===================================================

The previously qualified C5 validator is reused without editing its source.

Its historical four-component interface is mapped as follows:

Legacy validator label     Final semantic meaning
-------------------------------------------------
S0_C                       SINGLE_A
S0_D                       SINGLE_B
S1_B                       MULTI_A
S2_B                       MULTI_B

Primary validator construction:

SINGLE =
    S0_C + S0_D
  = SINGLE_A + SINGLE_B

  = 64,000 events

MULTI =
    S1_B + S2_B
  = MULTI_A + MULTI_B
