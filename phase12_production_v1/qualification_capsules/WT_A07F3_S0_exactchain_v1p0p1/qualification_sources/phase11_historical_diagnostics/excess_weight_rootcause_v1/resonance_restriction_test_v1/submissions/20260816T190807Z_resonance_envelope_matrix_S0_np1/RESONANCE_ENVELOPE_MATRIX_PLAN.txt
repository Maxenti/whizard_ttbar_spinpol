Interpretation rules
--------------------

Existing G2_S0 is the baseline U_G2 comparison.

No result from this diagnostic matrix is automatically authorized
as a production grid.

In particular:
  - do not select the numerically prettiest grid after observing results;
  - do not promote a restricted grid without a separate physics-definition
    decision;
  - do not interpret successful execution as integration qualification.

WT_W23 is specifically allowed to fail or destabilize.
Its purpose is to test whether the FCC-style resonance restrictions
change the previously observed deep-adaptation instability.

The 2M tests specifically investigate whether one large final fixed
iteration provides a more robust serialized max_abs_f state than
several smaller fixed iterations.

After integration:
  1. inspect all per-iteration trajectories;
  2. classify technical and adaptive stability;
  3. inspect serialized PHS/VG2 structure and hashes;
  4. only technically qualified grids proceed to matched generation
     envelope stress using predetermined RNG streams.
