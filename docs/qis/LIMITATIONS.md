# Limitations and safe interpretation

- The accepted 500 GeV source production is a tree-level, ISR-enabled, factorized spin-correlated hard-process sample.
- The nominal campaign has no collider-specific luminosity spectrum or beamstrahlung model.
- Level B defaults are parametric and must not be described as a particular detector without calibration.
- The default charged-lepton analyzing power is one; precision corrections can be supplied through configuration.
- Near threshold, finite-width, nonresonant, Coulomb, and resummation effects require dedicated samples.
- A global NLO K factor corrects a normalization but not differential shapes; Level C supports differential weights when provided.
- Negative-weight samples require careful effective-statistics and physical-fit diagnostics.
- CHSH values derived from collider density matrices are state diagnostics; a loophole-free Bell-test interpretation is outside the framework.
- PYTHIA settings must preserve the WHIZARD top decay chain. Changing resonance-decay settings requires new validation.
