# Runtime revision: PYTHIA 8.316 coherent LCG candidate

## Decision

For the WHIZARD ttbar spin/polarization campaign, the candidate coherent
runtime is revised from:

- WHIZARD 3.1.8
- PYTHIA 8.317

to:

- WHIZARD 3.1.8
- PYTHIA 8.316
- HepMC3 3.03.01
- GCC 14.3.0

using the LCG `devkey-head` `x86_64-el9-gcc14-opt` view.

## Candidate view

```text
/cvmfs/sft-nightlies.cern.ch/lcg/views/devkey-head/Fri/x86_64-el9-gcc14-opt/setup.sh
```

The runtime probe performed on lxplus found:

```text
whizard=/cvmfs/sft-nightlies.cern.ch/lcg/views/devkey-head/Fri/x86_64-el9-gcc14-opt/bin/whizard
WHIZARD 3.1.8

pythia8-config=/cvmfs/sft-nightlies.cern.ch/lcg/views/devkey-head/Fri/x86_64-el9-gcc14-opt/bin/pythia8-config
PYTHIA8_VERSION=8.316

HepMC3-config=/cvmfs/sft-nightlies.cern.ch/lcg/views/devkey-head/Fri/x86_64-el9-gcc14-opt/bin/HepMC3-config
HEPMC3_VERSION=3.03.01

gcc=/cvmfs/sft.cern.ch/lcg/releases/gcc/14.3.0-c8dfb/x86_64-el9/bin/gcc
g++=/cvmfs/sft.cern.ch/lcg/releases/gcc/14.3.0-c8dfb/x86_64-el9/bin/g++
```

## Rationale

No coherent Key4HEP or LCG/CVMFS runtime with both WHIZARD 3.1.8 and
PYTHIA 8.317 was found in the checked stable releases, Key4HEP nightlies,
or LCG `devkey` / `devkey-head` views.

The coherent LCG `devkey-head` view provides WHIZARD 3.1.8, PYTHIA 8.316,
HepMC3 3.03.01, and GCC 14.3.0 in one activated environment. This is a more
reproducible development and qualification candidate than mixing unrelated
package directories or using the older Key4HEP WHIZARD 3.1.5 / PYTHIA 8.315
runtime.

The hard process is generated by WHIZARD full six-fermion matrix elements.
PYTHIA is used for external-LHE showering, hadronization, residual decays,
and event transport to HepMC3. The known PYTHIA 8.317 changes do not appear
to be required for this external-LHE e+e- ttbar workflow. This revision does
not remove the need for Phase 7 shower-handoff validation.

## Reproducibility policy

This revision is acceptable only if the exact runtime is recorded in Phase 2
and propagated into later campaign manifests. The following must be retained:

- exact LCG view setup path;
- resolved paths of `whizard`, `pythia8-config`, and `HepMC3-config`;
- version strings;
- `LD_LIBRARY_PATH` and relevant runtime environment variables;
- compiler paths and versions;
- Git commit and dirty state;
- Phase 2 validation output directory;
- later Phase 7 shower-handoff validation records.

## Nightly-view caveat

The selected runtime is a nightly-style CVMFS view. Before final production,
one of the following must be true:

1. the exact view remains available and is explicitly frozen by Phase 2 and
   release manifests;
2. a stable LCG/Key4HEP release with equivalent versions is found and
   revalidated;
3. a local standalone generator stack is built, frozen, and revalidated.

Large production campaigns must not depend on a floating alias such as
`latest`. Use the explicit `Fri` view path above unless a newer candidate is
formally validated and the runtime contract is revised again.

## Validation consequence

After the runtime contract is revised from PYTHIA 8.317 to 8.316, Phase 2
should pass or at least no longer fail on the PYTHIA version mismatch when
run in the LCG `devkey-head/Fri` view.

Phase 7 remains the mandatory check for whether the selected PYTHIA/HepMC3
handoff is acceptable for the final external-LHE ttbar campaign.
